# GrizzyBot — Handoff

**Last updated:** 2026-11-14  
**Version:** in `project.yml` only (`MARKETING_VERSION`); release notes are in `CHANGELOG.md`

Native macOS Swift 6 app. Core is `GrizzyBotCore` (no SwiftUI). UI is `Sources/GrizzyBot`. Persistence: `~/Library/Application Support/GrizzyBot/`. Do not touch `config.json` / `.omo/`. Do not commit secrets. `project.yml` is the source of truth; `GrizzyBot.xcodeproj` is generated by `xcodegen generate` but also committed, so commit both when you add or remove files. `build/` and `opencode.json` are gitignored (copy `opencode.example.json`).

## Commands

```bash
swift test
swift build
xcodegen generate
./Scripts/make-app.sh
```

CI: `ci.yml` runs `swift test`, checks the committed `.xcodeproj` is in sync, builds Debug and Release, and runs the app unit tests (overlay pixel snapshots excluded; they only pass on the recording machine). `ui-tests.yml` runs the XCUITest overlays in their own job. `mlx-nightly.yml` covers MLX.

Run the overlay snapshots before committing UI changes: `Scripts/install-hooks.sh` installs a pre-commit hook that does it when UI files are staged (skip with `SKIP_SNAPSHOTS=1`).

Release (`.github/workflows/release.yml`): import Developer ID P12, Release build, notarize app + DMG, GitHub release. Needs repo secrets (see README).

## Architecture

| Target | Role |
|---|---|
| `GrizzyBotCore` | Models, store, agent loop, MCP, Composio, Keychain secrets, PBKDF2 auth, persistence, backup, diagnostics scrubber |
| `GrizzyBot` | SwiftUI shell, TTS, Sentry + scrubber, Mac Accessibility computer-use, overlays |
| `GrizzyBotRoutineAgent` | LaunchAgent helper — wakes app with `-grizzybot-tick-routines` when routines are due |
| `GrizzyBotCoreTests` | Swift Testing (store, agent, security, cron, product surface) |
| `GrizzyBotAppTests` | Overlay PNG golden regression (`Tests/GrizzyBotAppTests/Goldens/`) |
| `GrizzyBotUITests` | XCUITest overlays (`-uitest-open-*`). Xcode-only (not in `Package.swift`); run by `ui-tests.yml`. |

`GrizzyBotApp.swift` is `@main`.

`AppStore` (`@MainActor`, `@Observable`) keeps all stored state in `Store.swift`; its behaviour is split across `AppStore+*.swift` extensions by concern (`+AgentRun` send/queue/LLM loop, `+ToolExecution` one tool call, `+McpTools`, `+RunSupport`, `+MemoryAndSkills`, `+Conversation`, `+ChatLog`, `+Folders`, `+Auth`, `+UsageExport`, `+Avatars`, `+WaitAndWorkspace`, and the older ones). Swift extensions cannot hold stored properties, so new state goes in `Store.swift`; new behaviour goes in the matching extension, not the class body. Agent loop: `AgentLoop` + tools; `ScriptedRuntime` when no model is connected.

## Security

- **Secrets:** API keys, Composio, Box, TTS, Sentry DSN, OAuth, connection tokens → Keychain (`SecretStore`). JSON on disk and export/backup/snapshots are stripped.
- **Passwords:** PBKDF2-HMAC-SHA256 (600k iterations prod; 2k under XCTest). Legacy SHA-256 upgraded on sign-in.
- **Local account:** Launch uses `local@grizzybot.local` without a password gate. Optional sign-up/sign-in for named accounts.
- **Diagnostics:** Run logs and crash copy use `DiagnosticScrubber` (keys, tokens, home paths). Sentry `beforeSend` uses the same scrubber.
- **Computer:** In-app browser (WKWebView, http/https only) or This Mac (AX + Screen Recording). No Docker/cloud VM — UI only offers Auto, In-app browser, This Mac, Off.

- **Shell tool:** runs under `sandbox-exec`. Writes only inside the bot home and working folder; reads of `~/.ssh`, `~/.aws`, `~/.gnupg`, `~/.kube`, `~/.docker`, gcloud config and `~/Library/Keychains` are denied; network is denied unless the bot's "Shell network access" setting is on (legacy bots keep it on).
- **ai-memory bridge:** token from `AI_MEMORY_AUTH_TOKEN`, else Keychain (`com.grizzybot.app.ai-memory` / `auth-token`). `AiMemoryBridge.health` reports connected / backing off and why.

## Where the 0.10/0.11 pieces live

- **Trust layer** (all in `GrizzyBotCore`): `UntrustedContent` + `RunTaint` (fence outside content, per-run taint), `LeakScanner`, `SecretPlaceholders` / `OnePassword` / `AppStore+Secrets`, `AppStore+Leaks` (`guardedExecute` wraps every tool call: leak check, secret injection, redaction, reconnect cards, spans), `MemoryLedger` provenance tags, `MemoryFlush`, `ToolWatchdog`.
- **Delegation:** `BotRouting` (pure scoring + model-route validation), `AppStore+Dispatch` (Chief of Staff hand-off, room routing, capability hints). Taint crosses `message_bot` and room hand-offs through `inheritedTaint` / `lastRunTaint` in `Store.swift`.
- **Servers:** `WebhookReceiver` (8800), `ControlPlane` (MCP, 8801), `CompanionServer` + `CompanionPage` (8802) — all loopback by default; the companion can opt into network listening. `ControlPlane` and `CompanionServer` check `Host`/`Origin` through `RequestOriginGuard` (DNS-rebinding and cross-site defence) before the bearer token, which is header-only.
- **Tests:** `DispatchTests.swift` uses `ByBotClient`, which answers each bot from its own script (found via "You are <name>" in the system prompt) so several bots can run at once.
- Adding a Swift file means `xcodegen generate` and committing `GrizzyBot.xcodeproj` too.

- **Unreleased trio:** `ToolSelection` (+ `ToolSelectionView`, per-bot `toolSelection`, applied in `AppStore+AgentRun` / `+ToolExecution` / `AgentLoop`), `MeetingNotes` (`meeting_notes` tool, `/meeting`; transcript only, cannot join a call), `RoutingMemory` (cache + timings in `AppStore+Dispatch`, `routerTimeoutSeconds`). Not yet done: bump the version, refresh overlay goldens for the new settings UI.

## Product notes

- **Computer host prompt:** In-app browser vs This Mac (legacy `docker` → in-app browser).
- **Background routines:** Settings → Background routines registers `SMAppService.agent` (signed Release). Agent runs `open -g -a GrizzyBot --args -grizzybot-tick-routines`; app ticks headlessly (`NSApp.setActivationPolicy(.prohibited)`) and exits when runs finish.
- **Launch at login:** SMAppService main app; Debug/ad-hoc builds show an honest status message in Settings.
- **Signing:** Debug ad-hoc. Release: `Configs/Team.xcconfig` + `GrizzyBot.Release.entitlements` (iCloud). `Scripts/notarize.sh`.
- **iCloud:** Container `iCloud.com.grizzybot.app` — see `Configs/iCloud-setup.md`.
- **Overlay goldens:** `UPDATE_SNAPSHOTS=1 xcodebuild test -only-testing:GrizzyBotAppTests` to refresh PNGs.
